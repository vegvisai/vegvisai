# VegvisAI

En åpen veiviser som gjør bedrifter synlige og forståelige for alle AI-assistenter, fra ChatGPT og Claude til lokale språkmodeller. Kunden installerer ingenting, og bedriften gir ikke fra seg data.

**Status:** privat under oppbygging. Repoet åpnes ved lansering.

## Prinsipper

- Åpent for alle bedrifter, bransjer og AI-agenter.
- Bedriftene eier egne data, eget innhold, egne tjenester og egen betaling.
- Rangering, verifisering og tilgang kan aldri kjøpes.
- Plattformen guider og kobler; den eier ikke innholdet.
