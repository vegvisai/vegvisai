Guide · about 10 minutes

Add the snippet to your website

The generator gives you head-snippet.html: a short schema.org description of your business. Paste it into the head of your front page, and AI assistants can read who you are. That is all you need to register in the guide. The other files are optional.

Plans change. Several website builders only allow your own code on paid plans. What we write here was checked on 7 October 2026 against the builders' own help pages or well-known guides. Check your builder's help page if a menu is not where we say. The product names belong to their owners, and VegvisAI has no ties to any of them.

WordPress (your own installation)

  1. Install a plugin that adds code to the head, for example «WPCode» (Insert Headers and Footers): Plugins → Add new.
  2. Open Code Snippets → Header & Footer and paste the whole snippet into the Header box.
  3. Save. The snippet now appears on every page, which is fine.

On WordPress.com, plugins need the Business or Commerce plan (or the older Pro plan), according to WPBeginner.

Wix

Two ways:

  • Structured data on the page: open the front page in the editor, go to the page's SEO settings and add structured data markup. Paste only what is between <script …> and </script>, since Wix asks for the JSON-LD itself. See Wix: adding structured data.
  • Custom code: in the dashboard, Settings → Custom Code → Add Custom Code. Paste the whole snippet, place it in Head, and apply it to the front page. This needs a published site with a connected domain, and so a paid plan, according to Wix: embedding custom code.

Wix adds some local business data by itself when you fill in your business info. Our snippet can sit next to it.

Squarespace

  1. Open the front page's settings → Advanced → Page Header Code Injection.
  2. Paste the whole snippet and save.

Code injection is on the Core, Plus and Advanced plans, not on Basic (older plans: Business and Commerce, not Personal), according to Beyond Space.

Shopify

  1. Online Store → Themes → the three dots → Edit code.
  2. Open layout/theme.liquid and paste the snippet just before </head>.
  3. To show it only on the front page, wrap it: {% if template == 'index' %} … {% endif %}.

Take a copy of the theme first (Actions → Duplicate). Theme updates can overwrite your change, so check again after an update.

Webflow

Page settings for the home page → Custom code → Inside <head> tag. Paste the snippet and publish. Custom code may need a paid site plan. See Webflow's help pages.

Other builders, or a developer

Look for «custom code», «code injection», «header code» or «structured data» in the settings. If you have a web agency or a developer, send them the snippet and this sentence: «Please put this in the head of our front page.»

Check that it worked

  1. Run the AI check on your website. When it says «Looks ready to register», click the button. The address is filled in for you.
  2. Norwegian businesses can leave the organisation number out of the snippet if Enhetsregisteret lists the same website, and type it in the form instead.

Optional extras

llms.txt and ai-catalog.json help some agents and open guides, but you do not need them to register. Many builders do not let you upload files to the root or to /.well-known/. See the guide to the two files if yours does.
