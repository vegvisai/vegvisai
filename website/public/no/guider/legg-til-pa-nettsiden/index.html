Legg kodebiten på nettsiden

Generatoren gir deg head-snippet.html: en kort schema.org-beskrivelse av bedriften. Lim den inn i toppen (head) av forsiden, så kan AI-assistenter lese hvem dere er. Det er alt som trengs for å melde inn bedriften i veiviseren. De andre filene er valgfrie.

Abonnementer endrer seg. Flere nettsidebyggere tillater egen kode bare på betalte abonnement. Det vi skriver her ble sjekket 7. oktober 2026 mot byggernes egne hjelpesider eller kjente guider. Se hjelpesiden til din nettsidebygger hvis en meny ikke er der vi sier. Produktnavnene tilhører eierne sine, og VegvisAI har ingen tilknytning til noen av dem.

WordPress (egen installasjon)

  1. Installer en utvidelse som legger kode i head, for eksempel «WPCode» (Insert Headers and Footers): Utvidelser → Legg til ny.
  2. Åpne Code Snippets → Header & Footer og lim inn hele kodebiten i feltet Header.
  3. Lagre. Kodebiten kommer nå på alle sider, og det er helt greit.

På WordPress.com krever utvidelser abonnementet Business eller Commerce (eller det eldre Pro), ifølge WPBeginner.

Wix

To måter:

  • Strukturerte data på siden: åpne forsiden i editoren, gå til sidens SEO-innstillinger og legg til strukturerte data. Lim inn bare det som står mellom <script …> og </script>, siden Wix vil ha selve JSON-LD-koden. Se Wix: adding structured data.
  • Egen kode: i dashbordet, Innstillinger → Custom Code → Add Custom Code. Lim inn hele kodebiten, velg Head og bruk den på forsiden. Det krever en publisert side med eget domene, og dermed et betalt abonnement, ifølge Wix: embedding custom code.

Wix legger selv inn noe informasjon om bedriften når du fyller ut bedriftsinformasjonen. Kodebiten vår kan stå ved siden av.

Squarespace

  1. Åpne innstillingene for forsiden → Advanced → Page Header Code Injection.
  2. Lim inn hele kodebiten og lagre.

Code Injection finnes på abonnementene Core, Plus og Advanced, ikke på Basic (eldre abonnement: Business og Commerce, ikke Personal), ifølge Beyond Space.

Shopify

  1. Nettbutikk → Temaer → de tre prikkene → Rediger kode.
  2. Åpne layout/theme.liquid og lim inn kodebiten rett før </head>.
  3. Vil du ha den bare på forsiden, legg den inni {% if template == 'index' %} … {% endif %}.

Ta en kopi av temaet først (Handlinger → Dupliser). En temaoppdatering kan overskrive endringen, så sjekk igjen etter en oppdatering.

Webflow

Sideinnstillinger for forsiden → Custom code → Inside <head> tag. Lim inn kodebiten og publiser. Egen kode kan kreve et betalt abonnement. Se Webflows hjelpesider.

Andre nettsidebyggere, eller en utvikler

Se etter «custom code», «code injection», «header code» eller «strukturerte data» i innstillingene. Har dere et webbyrå eller en utvikler, send dem kodebiten og denne setningen: «Kan dere legge dette i head på forsiden vår?»

Sjekk at det virker

  1. Kjør AI-sjekken på nettsiden. Når den sier «Ser klar ut for påmelding», trykker du på knappen. Adressen er fylt inn for deg.
  2. Organisasjonsnummeret kan stå utenfor kodebiten hvis Enhetsregisteret har samme nettside. Da skriver du det i skjemaet i stedet.

Valgfritt i tillegg

llms.txt og ai-catalog.json hjelper noen agenter og åpne veivisere, men du trenger dem ikke for å melde inn bedriften. Mange nettsidebyggere lar deg ikke laste opp filer i roten eller i /.well-known/. Se guiden om de to filene hvis din gjør det.
